# Bundled skill provenance

- ai-usage-development: project-specific workflow authored for this checkpoint.
- i-have-adhd: snapshot of the user-configured skill; its existing MIT metadata
  and full instructions are retained.
- caveman: snapshot of the user-configured skill, preserving its instructions.
  The project's full-mode preference is stated in AGENTS.md.
- ryoku: snapshot of the installed Ryoku skill and its seven adjacent guides.
  The project is GPL-3.0 and keeps upstream attribution. Use that skill only for
  an actual Ryoku desktop; read the new host's vault instead of importing the
  original machine's generated maps or settings.

These are repo-local copies for continuity. Cloning does not install global
skills or change any other project's instructions. AGENTS.md supplies the
shared entry point for harnesses that do not auto-discover .agents/skills.
