# AI Usage module bug audit

Status: complete. Tested repairs are installed in the live widget. The user approved publication after review; the fork is published at `b650d0c474553931ef551332051e46fe3d651d62` and its working tree is clean.

## Findings repaired

| Area | Defect and resulting behavior |
| --- | --- |
| Displayed totals | OpenCode's cache-inclusive header omitted cache reads. It now prefers the explicit inclusive counter. |
| Numeric limits | QML's 32-bit counters wrapped at 2,147,483,647. Token/reset/mtime properties now retain larger values; future file dates do not imply fresh data. |
| Cache shape | Arrays and strings could be accepted as usage objects. Invalid top-level cache shapes now clear the view. Empty-history clearing already worked and needed no change. |
| OpenCode publication | Predictable temporary and lock paths could follow symlinks and expose 0644 output. Publication uses unique private files and atomic replacement; locks reject symlinks. Stale updates use the same publisher. |
| OpenCode inputs/retry | Non-finite source costs poisoned JSON; a contended collector reported success. Invalid numeric values are sanitized and contention requests the widget's retry path. |
| SQLite compatibility | URI-reserved path characters broke reads. Adaptive schemas without a SQL timestamp generated ORDER BY 0. Both private bundles now handle these layouts and preserve their existing cache tags. |
| Sessions | Older active sessions could fall outside the ten newest idle rows. Verified active sessions are prioritized before the idle cap. |
| Model counts | Badges counted only the bounded model payload. They now use the complete distinct count while retaining bounded visible rows. |
| Calendar boundaries | DST could lose a day's final hour and shift seven-/thirty-day boundaries. Today keeps 24 local clock slots, combines a repeated hour and leaves a skipped hour empty. Collector periods share calendar midnights and displayed hourly boundaries. |
| Price validation | Malformed frozen rate fields or bundled JSON shapes could raise errors. Valid context thresholds over one million tokens were rejected as if they were currency rates. Both now validate independently and fail unavailable rather than fabricate prices. |
| Claude failure handling | Unavailable pricing storage stopped token collection; a nested ledger date could throw a type error. Token collection continues with an explicit unavailable estimate, preserving unreadable state. |
| Claude response metadata | Initial missing model metadata could hide a later known model. Empty synthetic error usage created spurious model rows. Final known metadata is retained and zero-usage rows do not create models. |
| Standalone installation | Copy/reload failures could lose the previous widget. Installation stages a complete copy, serializes changes and rolls back failures. A regression also verifies that the reloader cannot inherit the install lock. |
| Developer tooling | An obsolete bundled diagnostic and demo generator accessed shared global caches. The diagnostic was removed; demo generation requires an explicit directory, refuses existing caches and creates files exclusively. |

Native session/model labels are rendered as plain text. Five dead local variables and an unclosed fixture SQLite connection were also removed or corrected.

Authentication was not modified, and no paid model prompts were sent.
