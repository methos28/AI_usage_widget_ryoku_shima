# Durable decisions

- Keep the standalone app canonical and mirror runtime deliberately to the
  optional Ryoku fork. Preserve intentional manifest and CLI/source labels.
- Keep collectors in widget/bin and caches private. Never replace shipped
  collectors or edit the package-owned shell as a local experiment.
- Preserve request identity and historical rates. Tests isolate state and
  disable price downloads. API Value is not account billing.
- Show real quota measurements; unknown/stale remains explicit. Preserve
  native lifecycle/process evidence instead of recency-based activity guesses.
- Keep all-time trend at 45 days and Activity at 63 dated squares.
- Scope live work carefully, back up known-good code and honor explicit
  preview-before-commit requests. Do not roll runtime data back with UI code.
- Publish only when requested, keep normal hooks, preserve history, and use
  the exact named user repository/branch. No unrequested PR/review messages.
- User chat preferences travel in the two bundled style skills. Files and
  external descriptions remain ordinary prose.
