# Project memory

Read `current-state.md` first, then `decisions.md`. `local-machine.md` records
observations tied to the original host; it is not a configuration template.

`history/` preserves the AI Usage notes authored in the original Rashin vault.
They include old paths, branch names, test counts and superseded wait/hold
instructions. Read them as dated evidence alongside PROJECT_LOG.md. The current
handoff, current-state and current user request determine what work is active.
No generated system vault, credential files, native sessions, databases,
private cache snapshots or machine-wide settings are included.
